# Sol.reply_sanitizer 1.5.3 分享源码（2026-10-30）

清理漏入公开回复的明确思考标签、已知异常标记与明确中文思考标题，并提供独立的外观过滤开关。1.5.3 在 1.5.2 上修复两个已证实的格式问题；没有新增任意内容关键词，也没有调整默认配置。本目录是隔离修复源码，不表示已经部署到机器人。

## 1.5.3 修复

- `strip_artifacts` 增加精确句首空标记 `[_thought _]` 的识别，允许其中的空格、制表符或换行；只删除空标记，保留后面的正文。代码、引用、正文中间的同一标记与带内容的相似结构均保留。关闭该开关可保持旧行为。
- `strip_tags` 识别已有标签别名的同名空畸形块，例如 `<thought </thought>`：开标签漏了 `>`，但立即跟着同名闭合标签。旧版可能把后续正常正文误当未闭合思考而全部清空；新版只清理这一精确空结构。正常未闭合思考块仍隐藏到末尾，嵌套块不提前结束。关闭该开关可保留原文。

这两个修复分别解决格式残标与正常正文误删。空标记本身不能证明整段内部分析已经泄露。

## 核心防漏与外观开关

| 配置 | 用途与边界 | 兼容默认值 |
| --- | --- | --- |
| `strip.strip_tags` | 清理 XML 思考块及句首角括号思考块；删除标签包住的内容，未闭合块隐藏到末尾 | `true` |
| `strip.strip_chinese_analysis` | 识别句首“思考过程 / 思想过程 / 思维链”等明确标题，只保留显式最终回复；无明确分界时返回空串 | `true` |
| `strip.strip_artifacts` | 清理已知边缘伪标记、句首空 `[_thought _]` 与整条双角括号包装；主要是格式清理 | `true` |
| `strip.leading_markers` | 清理配置指定的句首占位标记；留空关闭 | `"[::]"` |
| `strip.strip_reason_words` | 清理句首独立推理标签词及已有明确英文起草结构；不是任意词检索 | `true` |
| `preamble.mode` | 按已有明确推理句式切前言；`heuristic` 需要标签/装饰等证据，`always` 更积极，`off` 只关闭此项 | `"heuristic"` |
| `strip.strip_decorations` | 删除句首指定装饰字符（默认 🧠💭🫧）；不能据此证明删除了思考正文 | `true` |
| `strip.strip_emoji` | 过滤代码外的常见文本 emoji；属于外观偏好，不处理图片表情包 | `true` |
| `strip.strip_private_use` | 过滤代码外 Unicode 私用区字符，可能同时去掉自定义字体图标；属于外观偏好 | `true` |

需要防止明确思考块外发时，建议保留 `strip_tags` 与 `strip_chinese_analysis`。希望保留正常文本 emoji / 自定义图标时，可分别关闭 `strip_emoji` / `strip_private_use`；这不会关闭标签和中文标题规则。1.5.3 保留旧默认值，避免升级时悄悄改变用户设置。规则数量与防漏效果不能等同；外观命中次数也不能当作避免思考泄漏的次数。近期未命中的规则不能据此断言长期无用。

不会保证识别所有自然语言分析，也不应靠扩大关键词列表承诺杜绝泄漏。正常代码示例、数学分析和正文中标记引用受到保护；明确思考块内部的代码围栏不会使其中内容重新可见。未命中规则时不额外改动首尾空白。前言阈值保持 `min_cjk_ratio=0.5`、`max_cut_chars=1500`。

## 钩子与数据范围

四个钩子分别在模型返回后、发送前处理 `response`，并在 Planner/Replyer 请求副本中清洗明确 Assistant 思考块；不修改数据库或其他角色历史。已有纯中文分析或映射为 User 的历史不保证清理。请求历史清洗与新回复净化的范围不同，历史重复出现也不代表新模型又生成了一次。

除改写 `response` 外，其余钩子参数保持透传，包括分段和错字策略。空串依赖宿主原有发送检查阻止该条发送；不会恢复成原文。净化异常保持原有可用性策略：记警告并放行原文。后续插件仍可能改写结果，因此本插件不能作绝对防漏保证。
